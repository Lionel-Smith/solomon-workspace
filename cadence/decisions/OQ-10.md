## Daily-slot budget impact

Per plan Appendix D: GitHub Routines are event-driven, ~0-5 PR reviews + 0-3 CI triages typical = 0-8 daily slots. Combined with the 4-6 scheduled Routines, peak Mon-Thu ~6/day, Fri ~9/day. Well under the 15/day Anthropic Max cap.

If load spikes above 80% utilization (sustained), the plan's mitigation is to skip review on PRs <10 lines or docs-only (already in the `github-pr-review` prompt skip logic — see plan §4.7).

## Excluded repos (intentionally)

- All client repos (CaribbeanLeaf, Ready Bahamas, NIB, ClinicConnect, Made-in-Bahamas, etc.) — not the founder's primary review surface; client review goes through separate channels.
- Personal experimentation repos.

## Why this matters

Adding a new repo later requires:
1. Installing the Anthropic GitHub App on that repo
2. Updating each Routine's `repos` array
3. Re-registering the Routine via `cadence_routine_register`

Best to enumerate now.

## How to override

Edit the "Resolved repo set" table before `ROUTINE-08/09/10` fires. Removing a repo from the v1 list defers it to v1.2+.
